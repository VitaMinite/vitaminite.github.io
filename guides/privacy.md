## Google 접근 권한과 데이터 사용

Google 연결은 이용자가 브라우저에서 계정과 접근 권한을 승인한 경우에 시작합니다. 앱은 다음 API(Application Programming Interface) 권한을 요청합니다.

| 권한 | 필요한 기능 |
|---|---|
| `calendar.calendarlist.readonly` | 접근 가능한 캘린더 목록 확인 |
| `calendar.events` | 일정 조회, 등록, 수정, 삭제와 반복 일정 처리 |
| `tasks` | 할 일 목록과 할 일 조회, 생성, 수정 및 삭제 |

인증과 동기화 요청은 이용자 기기에서 Google로 직접 전송됩니다. 이용자가 등록하거나 수정한 일정과 할 일은 Google 계정에 반영되며, 공유 캘린더의 정보는 해당 캘린더의 공유 권한에 따라 다른 사람에게 보일 수 있습니다. Google의 정보 처리는 [Google 개인정보처리방침](https://policies.google.com/privacy?hl=ko)도 적용받습니다.

VitaMinite는 Google에서 받은 정보를 이용자가 요청한 일정과 할 일 기능에만 사용합니다. 이를 판매하거나 광고, 신용평가, 대출 심사 또는 범용 인공지능 모델 학습에 사용하지 않습니다. 운영자가 Google 데이터에 자동으로 접근하거나 이를 열람하는 기능은 없습니다. 지원을 위해 특정 자료를 확인해야 할 때에는 이용자가 명시적으로 제공한 범위만 확인합니다.

VitaMinite의 Google API로부터 받은 정보의 사용과 다른 앱으로의 전송에는 Limited Use 요구사항을 포함한 [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)를 적용합니다.

## 연결 해제와 삭제 방법

1. 앱의 **연결** 화면에서 **Google 연결 해제**를 선택합니다. 미동기화 변경이 남아 있으면 내용을 확인한 뒤 해제를 취소하거나 변경을 폐기하고 해제할 수 있습니다.
2. 연결 해제가 완료되면 저장된 인증정보와 해당 계정의 로컬 캐시, 대기 변경, 충돌 및 알림 기록을 삭제합니다. **Google에 저장된 원본 일정과 할 일은 연결 해제만으로 삭제되지 않습니다.** 원본을 지우려면 앱 또는 Google 서비스에서 해당 항목의 삭제를 요청해야 합니다.
3. 앱은 Google 접근 권한의 폐기도 요청합니다. 오프라인이나 통신 오류로 결과를 확인하지 못하면 이를 알립니다. 이 경우 [Google 계정의 서드 파티 연결 관리](https://myaccount.google.com/connections)에서 VitaMinite에 부여한 접근 권한을 직접 철회할 수 있습니다.
4. Google 쪽에서 권한을 철회하는 것만으로 기기에 남아 있는 자료가 지워지지는 않습니다. 로컬 자료 정리에는 앱의 연결 해제도 필요합니다. 앱을 사용할 수 없거나 일반 설정까지 정리해야 한다면 아래 문의처로 삭제 방법을 요청할 수 있습니다.

앱 제거만으로 모든 로컬 파일과 자격 증명이 자동 삭제된다고 보장하지 않습니다. 앱의 데이터 삭제는 저장 항목을 제거하는 방식이며, 디스크의 모든 흔적이나 별도로 만든 백업까지 복구 불가능하게 지우는 기능은 아닙니다. 이용자가 만든 백업이나 내보낸 자료는 이용자가 별도로 관리해야 합니다.
