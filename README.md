# VitaMinite 소개 사이트

<https://vitaminite.github.io/>에 공개되는 소개 사이트의 소스입니다. Astro로 만들고, `main`에 push하면 GitHub Pages로 배포합니다.

- 미리보기: `npm install` 후 `npm run dev`
- 빌드: `npm run build`
- 개인정보처리방침 원본은 [`guides/privacy.md`](guides/privacy.md), 서비스 약관 원본은 [`guides/terms.md`](guides/terms.md)입니다. Astro 페이지가 이 원본을 읽어 표시합니다.
- 공개 주소: [개인정보처리방침](https://vitaminite.github.io/privacy/), [서비스 약관](https://vitaminite.github.io/terms/).
- PR에서는 빌드만 검사하고, `main`에 병합된 변경만 GitHub Pages에 배포합니다.

설치 파일과 이슈는 [VitaMinite/vitaminite](https://github.com/VitaMinite/vitaminite)에 있습니다. 이 저장소의 내용은 모든 권리가 VitaMinite에 있으며, 사용·복제·재배포를 허락하지 않습니다.
